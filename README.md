# flatTube

Plays a low-resolution video (30x4 px) on a single SK6812 RGBW LED strip
wired in a serpentine ("snake") pattern inside a light box, driven by a
Raspberry Pi Zero W.

This is a stripped-down spinoff of [fpTube](../fpTube), which drives 200
tubes of 120 LEDs each (a 200x120 video wall) over DMX/serial/OSC. flatTube
keeps only what's needed to play video on one strip: no DMX, no serial, no
OSC (a web frontend for control is planned later).

## Hardware layout

The strip is 120 LEDs total, wired as 4 rows of 30 with no filler LEDs
between rows:

- Row 0 (visual top): LEDs 0-29, right to left
- Row 1: LEDs 30-59, left to right
- Row 2: LEDs 60-89, right to left
- Row 3 (visual bottom): LEDs 90-119, left to right

The physical strip is described as wired bottom-to-top, but LED row 0
reads as the visual top of the box, not the bottom -- confirmed against
the hardware with `tools/gen_test_pattern.py`'s R/G/B/R pattern. See
`src/mapping.c` for the index calculation.

## Building

Only builds on the Raspberry Pi (the vendored driver in `src/vendor/`
talks to the BCM283x DMA/PWM peripherals directly via `/dev/mem`).

Prerequisites on the Pi: `libpng-dev`, a C compiler, and GPIO access
(typically run as root, or with the appropriate group permissions for
`/dev/mem`).

```
make
sudo ./flattube videos/test_pattern
```

## Usage

```
./flattube [options] <frames-dir>
  <frames-dir>              directory of 30x4 PNG frames to play in a loop
  -g, --gpio <pin>          GPIO pin driving the LED strip (default 18)
  -b, --brightness <0-255>  overall brightness (default 255)
  -f, --fps <n>             playback frame rate (default 25)
```

`<frames-dir>` must contain PNG files, all exactly 30x4 pixels, named so
that alphabetical order matches playback order (e.g. `frame_0000.png`,
`frame_0001.png`, ...).

## Videos

- `videos/test_pattern/` -- generated by `tools/gen_test_pattern.py`. Four
  solid-color rows (red/green/blue/red) with a bright marker sweeping
  across all rows in lockstep, for confirming wiring/direction.
- `videos/fire/` -- the fpTube "006-Fire" sequence, downsampled from
  200x120 to 30x4 by `tools/convert_fire.py`.

Regenerate either with:

```
pip install -r tools/requirements.txt
python3 tools/gen_test_pattern.py
python3 tools/convert_fire.py
```

## Layout

```
src/            application code (main.c, mapping.c, pngseq.c)
src/vendor/     vendored rpi_ws281x DMA/PWM driver, unmodified
tools/          Python scripts for generating/converting video frame sequences
videos/         PNG frame sequences played by flattube
```
